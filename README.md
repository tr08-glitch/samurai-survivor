# 侍サバイバー

妖怪の夜を、ひとり斬り抜ける。和風ローグライク・サバイバー(試作版)。

- ブラウザだけで遊べる、1ファイル(`index.html`)のゲームです。ビルドは不要です。
- 操作:画面をドラッグして移動(PCは WASD / 矢印キー)。攻撃は自動。

## 公開のしかた(Render の Static Site)

1. このフォルダの中身を GitHub のリポジトリに置く(`index.html` がリポジトリの一番上にあること)
2. Render で「New +」→「Static Site」→ そのリポジトリを選ぶ
3. Build Command は空、Publish Directory は `.`(ドット1つ)にして作成
4. 表示された `https://○○.onrender.com` が公開URL

## 更新のしかた

`index.html` を差し替えてコミットすると、Render が自動で公開し直します。

## 開発用の操作

URLの末尾に `?debug` を付けると、試遊用のボタン(速度変更、レベル+1、全員解放、全マップ解放、図鑑の全開放、小判+1,000,000、勾玉+1,000,000)が出ます。

## メモ

- 小判・強化・雇用・討伐済みの記録は、遊んでいる端末のブラウザ(そのURLごと)に保存されます。別のURLで遊ぶと、記録は引き継がれません。
